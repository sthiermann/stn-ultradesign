# Research the current project

Use when a recommendation depends on changing platform behavior, a user-selected visual reference, an unfamiliar workflow or an unresolved technical constraint. This package contains original operating instructions, not a provider catalogue or a fixed external reading list.

## Turn a question into a testable rule

1. State what must be learned and why it changes the design: a navigation convention, material behavior, interaction state, metric meaning or implementation limit.
2. Inspect current primary guidance for the chosen reference and the actual target platform. Examine real screens and relevant movement as well as prose. Check publication/version and distinguish normative requirements, implementation guidance, measured research and stylistic preference.
3. Keep a project-local evidence record with the specific observation, scope, access method, date, version and limitations. Describe behavior in original words. Do not copy external skill instructions, templates, code, artwork or assets into this package or the deliverable.
4. Translate the observation into a project-specific decision and a visible acceptance condition. Explain the task fit, implementation constraint and allowed fallback. Use [reference-translation.template.md](../assets/reference-translation.template.md) when the chosen direction needs detailed comparison.
5. Verify the rule in the rendered product’s affected usages, relevant input states and supported variants. Record what was inspected and what remains unverified.

Research follows the current user’s direction. A previous project’s palette, reference release, material or navigation arrangement is not a default. Established patterns are candidates with a scope; frequency of use does not prove they fit this application.

## Keep evidence separate from publication

Keep source URLs, captured observations and comparison notes in the project’s private working area unless its owner explicitly requests a research report. Do not add provider comparisons, named inspiration lists, external source catalogues or third-party excerpts to this reusable repository. Public instructions should express independently written decisions, checks and templates. Preserve any attribution or license notice that an included dependency actually requires; publication preferences never authorize removing a mandatory notice.

Report claims at the level the evidence supports. A search result is not a full page inspection; documentation is not live behavior; a still image is not a motion review; an abstract is not a full study. If a required source or environment is unavailable, retain the uncertainty and use the strongest available evidence without claiming equivalence.
